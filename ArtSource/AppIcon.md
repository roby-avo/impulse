# Physics Playground app icon

`Assets/Resources/UI/AppIcon.png` is the generated master image used for the
runtime brand mark and the macOS application icon. Created with the built-in
image_gen tool (imagegen skill), then copied into the project without editing.
Unity imports and resizes it for the app bundle; the image is not fetched at runtime.

Final generation prompt:

> Use case: stylized-concept. Asset type: macOS game app icon for Physics Playground, a stylized rooftop robot ring-out duel. Create a polished square 1024x1024 app icon, one large friendly but competitive armored robot head in white ceramic armor with a dark navy visor and two crisp cyan illuminated eyes, subtle orange accent on one side, cyan lower collar. Thick readable silhouette, premium playful 3D game rendering, restrained metallic highlights. Centered head fills 75% of an inset rounded-square deep midnight blue tile, subtle cyan rim light and a small angular orange impact spark at upper right. Transparent outside the rounded-square tile, generous consistent padding. No words, no letters, no watermark, no additional icons. Design should remain clearly recognizable at 32 pixels.
